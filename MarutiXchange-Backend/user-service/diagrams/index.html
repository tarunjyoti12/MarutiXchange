📋 System Overview

The User Service is a Spring Boot microservice that handles user authentication, registration, OTP verification, password management, and document uploads.

🔐 Authentication

JWT-based authentication with Bearer tokens and 24-hour expiry

📧 Email Services

Welcome emails, OTP delivery, and password reset links

🔒 Account Security

Account locking after 5 failed attempts for 30 minutes

📄 Document Management

File upload and storage with metadata tracking

Key Components

  • UserController - REST API endpoints
  • UserService - Business logic implementation
  • UserRepository - Database access layer
  • EmailService - Email sending service
  • DocumentService - File management
  • JwtUtil - JWT token generation and validation
  • PasswordEncoder - BCrypt password encoding

📊 Data Flow Diagrams

User Registration Flow

Client → Controller → Service → Repository → Database
                   ↓
              PasswordEncoder (encode password)
                   ↓
              EmailService (send welcome email)
                   ↓
              Response (201 CREATED)

User Login Flow

Client → Controller → Service → Repository → Database
                   ↓
              Check account lock status
                   ↓
              Verify password (PasswordEncoder)
                   ↓
              Generate JWT token (JwtUtil)
                   ↓
              Response (200 OK with token)

OTP Verification Flow

Client → Controller → Service → Repository → Database
                   ↓
              Generate 6-digit OTP
                   ↓
              EmailService (send OTP)
                   ↓
              Client verifies OTP
                   ↓
              Update isVerified flag
                   ↓
              Response (200 OK)

Password Reset Flow

Client → Controller → Service → Repository → Database
                   ↓
              Generate UUID reset token
                   ↓
              EmailService (send reset link)
                   ↓
              Client clicks reset link
                   ↓
              Encode new password
                   ↓
              Update password in database
                   ↓
              Response (200 OK)

Document Upload Flow

Client → Controller → Service → Repository → Database
                   ↓
              Validate file (size, type)
                   ↓
              Generate unique filename
                   ↓
              Upload to FileStorage (S3/Local)
                   ↓
              Save metadata to database
                   ↓
              Response (200 OK with file URL)

TDD Workflow

RED → GREEN → REFACTOR
  1. RED: Write failing test
  2. GREEN: Write minimal implementation
  3. REFACTOR: Improve code quality
  4. REPEAT: Continue with next test

Exception Handling

Exception HTTP Status Description
EmailAlreadyExistsException 409 CONFLICT Email already registered
InvalidCredentialsException 401 UNAUTHORIZED Invalid email or password
AccountLockedException 403 FORBIDDEN Account locked due to failed attempts
UserNotFoundException 404 NOT FOUND User not found in database
InvalidOtpException 400 BAD REQUEST Invalid or expired OTP
InvalidTokenException 400 BAD REQUEST Invalid or expired reset token
